NEXO APK — сборка через GitHub с телефона

1. Создай новый репозиторий на https://github.com/new
   Название: nexo-android
   Можно выбрать Private.
2. Распакуй этот ZIP на телефоне.
3. Загрузи ВСЕ файлы и папки из распакованной папки в репозиторий GitHub, сохранив структуру папок.
   Важно: должна быть папка .github/workflows с файлом build-apk.yml.
4. Открой репозиторий на GitHub → Actions.
5. Выбери "Build Nexo APK" → Run workflow → Run workflow.
6. Дождись зелёной галочки. Открой завершившуюся сборку и внизу раздел Artifacts.
7. Скачай Nexo-APK.zip и распакуй его. Внутри будет app-debug.apk.
8. Открой APK на телефоне и разреши установку из этого источника, если Android спросит.

Если вкладки Actions нет: в репозитории открой Settings → Actions → General и разреши Actions.

Примечание: сборка упаковывает HTML-сайт в Android-приложение. Если в самом сайте нужны Firebase/серверные настройки, они должны быть корректными; APK не исправляет ошибки сайта автоматически. Не публикуй секретные ключи в открытом репозитории.
